## 🎯 功能說明

### 管理員操作流程

1. **訪問管理頁面**
   ```
   https://your-domain.netlify.app/admin/rich-menu.html
   ```

2. **上傳三張圖片**
   - 左：創建貼圖的圖片（會加上紅色底「創建貼圖」）
   - 中：我的貼圖的圖片（會加上綠色底「我的貼圖」）
   - 右：爆量出圖的圖片（會加上藍色底「爆量出圖」）⭐ 新

3. **預覽合成效果**
   - 系統自動合成 2500 x 843 px 圖片
   - 顯示預估檔案大小
   - 確認符合 LINE 規格

4. **更新 Rich Menu**
   - 點擊「合成並更新 Rich Menu」
   - 系統自動壓縮並上傳
   - 所有用戶的 Rich Menu 立即更新

## 💡 設計建議

### 右下角「爆量出圖」圖片建議

**主題**: 快速、經濟、效率

**視覺元素**:
- 🚀 火箭（代表快速）
- 💰 金幣或價格標籤（代表經濟實惠）
- 數字「3」或「40」（代表 40 張 = 3 組）
- 明亮的顏色（橙色、藍色）


**配色建議**:
- 背景：漸層藍色或橙色
- 文字：白色
- 圖示：大而清晰的 🚀

## 🔍 保留的功能

### 「示範圖集」功能仍然可用

雖然 Rich Menu 改為「爆量出圖」，但用戶仍可以通過以下方式訪問示範圖集：

1. **輸入指令**
   - 「示範圖集」
   - 「範例」
   - 「作品集」

2. **功能說明中的連結**
   - 在功能說明頁面仍有示範圖集的入口

3. **Quick Reply 按鈕**
   - 某些訊息中仍保留「示範圖集」按鈕

**原因**: 示範圖集對新手了解功能仍有價值，只是不需要佔據 Rich Menu 的黃金位置。
