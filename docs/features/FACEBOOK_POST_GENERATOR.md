# Facebook 貼文生成器功能說明

**更新日期**: 2026-02-01  
**功能位置**: 管理後台首頁 (`/admin/index.html`)

---

## 📋 功能概述

Facebook 貼文生成器是一個 AI 驅動的社群行銷工具，幫助管理員快速生成不同角度、不同語氣的 Facebook 貼文，用於推廣「貼圖大亨」服務。

### 核心特色

✅ **多主題輪替** - 自動避免重複相同賣點  
✅ **多語氣選擇** - 親切、專業、幽默、故事感  
✅ **智能 CTA** - 根據不同目標生成對應的行動呼籲  
✅ **一鍵生成** - 使用 DeepSeek AI 快速產出高質量文案  
✅ **經濟實惠推廣** - 特別強調「極速上架」的省錢優勢

## 🔄 主題輪替機制

系統內建 7 大主題，自動輪替避免重複：

1. **在 LINE 內直接操作** - 強調便利性
2. **照片變貼圖** - 強調實用性
3. **零設計也能做** - 降低門檻
4. **流程省時省力** - 強調效率
5. **送禮/社交話題** - 強調情感價值
6. **創作者上架** - 強調變現機會
7. **Rich Menu / 官方帳號玩法** - 強調互動性

**智能排除**: 點擊「換一篇」時，系統會自動排除最近使用過的 3 個主題，確保內容多樣性。

2. **輪替使用引導方向**

   - 週三：優惠券活動（限時優惠）

4. **追蹤成效**
   - 記錄不同主題的互動率

## 🛠️ 技術實現

### 前端 (index.html)
- 選項分組：推薦功能、優惠活動、一般引導
- 即時預覽：顯示當前選擇的主題和語氣
- 一鍵複製：方便快速使用

### 後端 (admin-facebook-posts.js)
- AI 引擎：DeepSeek API
- 智能 Prompt：根據不同 CTA 生成專屬引導文字
- 主題排除：避免重複使用相同賣點

### API 端點
```
POST /.netlify/functions/admin-facebook-posts?action=generate
```

**請求參數**:
```json
{
  "tone": "friendly",
  "ctaStyle": "quick-launch",
  "websiteUrl": "https://sticker-tycoon.netlify.app",
  "officialLineUrl": "https://line.me/R/ti/p/@sticker-tycoon",
  "excludeTopicKeys": ["line-in-bot", "turn-photo-to-stickers"]
}
```

**回應範例**:
```json
{
  "success": true,
  "topic": {
    "key": "fast-workflow",
    "label": "流程省時省力"
  },
  "tone": "friendly",
  "post": "生成的貼文內容...",
  "apiUsed": "DeepSeek"
}
```
