## 🎯 設計理念

### 為什麼把「爆量出圖」放在 Rich Menu？

1. **最高曝光率**
   - Rich Menu 永遠顯示在聊天室底部
   - 用戶隨時可見，無需輸入指令
   - 是最重要的功能入口

2. **降低使用門檻**
   - 不需要記住「爆量出圖」這個指令
   - 一鍵點擊即可開始
   - 適合所有用戶（包括不熟悉指令的用戶）

3. **強化價值主張**
   - 與「創建貼圖」並列，暗示同等重要
   - 右下角位置符合視覺習慣（右手操作）
   - 突出「最經濟實惠」的方案

### 為什麼移除「示範圖集」？

1. **使用頻率較低**
   - 示範圖集主要用於新手了解功能
   - 不是核心轉換路徑
   - 可以透過其他方式訪問（如功能說明）

2. **優先級調整**
   - 「爆量出圖」是主要變現功能
   - 需要最高的曝光和點擊率
   - 符合商業目標

3. **替代方案**
   - 示範圖集仍可透過輸入「示範圖集」訪問
   - 可在功能說明中加入連結
   - 可在歡迎訊息中展示
