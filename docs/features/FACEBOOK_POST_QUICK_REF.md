# Facebook 貼文生成器 - 快速參考

## 🎯 三大推廣重點

### 1️⃣ 極速上架（最經濟實惠）⭐
**何時使用**: 推廣省錢方案、吸引預算有限的用戶

**關鍵賣點**:
- 💰 40 張獲得 3 組貼圖（共 54 張）
- ⚡ 一鍵搞定，懶人專用
- 🎯 最經濟實惠的選擇

**建議語氣**: 親切、幽默  
**發文頻率**: 每週 2 次  
**最佳時段**: 週一早上、週四晚上

---

### 2️⃣ 優惠券兌換（限時優惠）🎫
**何時使用**: 節日活動、新用戶獲取、提升轉換率

**關鍵賣點**:
- 🎁 免費張數大放送
- ⏰ 限時限量，先搶先贏
- 🔥 營造稀缺感和急迫感

**建議語氣**: 幽默、親切  
**發文頻率**: 活動期間每天 1 次  
**最佳時段**: 週三中午、週五晚上

---

### 3️⃣ 關注 FB 享驚喜（長期關係）👍
**何時使用**: 建立社群、培養忠實粉絲、長期經營

**關鍵賣點**:
- ✨ 獨家優惠定期發放
- 🎉 限定抽獎活動
- 💡 創作靈感與技巧分享

**建議語氣**: 親切、故事感  
**發文頻率**: 每週 1 次  
**最佳時段**: 週五晚上、週日下午

## 💡 快速操作步驟

1. **進入管理後台** → `/admin/index.html`
2. **輸入 ADMIN_API_KEY** → 點擊「保存」
3. **選擇語氣** → 親切/專業/幽默/故事感
4. **選擇引導方向** → 極速上架/優惠券/FB 關注
5. **點擊「生成貼文」** → 等待 AI 生成
6. **點擊「複製」** → 貼到 Facebook 發布

## ⚠️ 注意事項

### ✅ 應該做的
- 定期輪替不同主題
- 搭配視覺素材（圖片/影片）
- 回覆用戶留言，增加互動
- 追蹤成效，持續優化

### ❌ 避免做的
- 連續發布相同主題
- 過度承諾（如「保證上架」）
- 忽略用戶留言
- 只發廣告，不提供價值

## 🚀 進階技巧

### 1. A/B 測試
同一主題用不同語氣發布，比較成效

### 2. 時段測試
測試不同時段的互動率：
- 早上 8-10 點（通勤時間）
- 中午 12-14 點（午休時間）
- 晚上 20-22 點（休閒時間）

### 3. 視覺搭配
- 極速上架 → 使用「快速」、「效率」相關圖片
- 優惠券 → 使用「禮物」、「驚喜」相關圖片
- FB 關注 → 使用「社群」、「互動」相關圖片

### 4. 互動技巧
- 在留言區置頂「如何開始」的說明
- 回覆留言時附上官方帳號連結
- 分享用戶的成功案例

## 📞 常見問題

**Q: 多久發一次文比較好？**  
A: 建議每週 3-4 次，避免過度打擾用戶

**Q: 哪個引導方向效果最好？**  
A: 根據測試，「極速上架」和「優惠券」轉換率較高

**Q: 可以同時使用多個引導方向嗎？**  
A: 可以，但建議一篇貼文專注一個主要 CTA

**Q: 如何提高互動率？**  
A: 使用問句開場、鼓勵留言、舉辦抽獎活動
